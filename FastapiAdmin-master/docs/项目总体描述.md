## 一、项目概述

智慧胸痛中心管理平台是面向胸痛中心（可扩展至卒中中心等急危重症专科）的**专病信息化质控平台**，覆盖「患者建档 → 病例填报 → 审核质控 → 随访管理 → 数据分析」全流程，并提供远程心电、三会模板、胸痛学院、认证知识库问答、AI 识别等增值能力。

### 系统组成（本仓库）

| 组成 | 说明 | 技术 | 端口 |
|---|---|---|---|
| FastAPI 后端 | 三端共用的 API 与服务层 | Python 3.12+ / FastAPI | 8002 |
| Web 管理端 | 运营/质控人员使用 | Vue3 + Element Plus | 5180 |
| App 医生端 | 医生/审核现场使用 | uni-app（H5/小程序/App） | 5190 |

> ⚠️ **边界说明**：旧文档提到的「DataMAX 运行数据大屏」是**云端外部服务（max.datahunter.cn），不在本仓库代码内**，属于可选的展示层，本文不再将其列为系统组成部分。本仓库不包含大屏前端代码。

## 五、两个核心设计亮点

1. **动态路由插件机制**：`app/core/discover.py` 扫描 `module_*/**/controller.py`，目录名 `module_xxx` 自动映射为 URL 前缀 `/xxx`。新增业务模块只需在 `app/plugin/` 下建目录 + `controller.py`，**无需手动注册路由**。
2. **字段字典驱动的填报体系**：`app/plugin/module_cpx/fields.py` 定义 67 个胸痛标准字段（`field_code` 英文编码为唯一主键），模板与填报数据都引用它。Web 详情页与 App 填报页均依赖同一字典，保证三端字段一致。

## 六、业务域一览（module_cpx，前缀 /api/v1/cpx）

| 模块 | 职责 |
|---|---|
| doctor | 医生端主接口：建档、填报、AI 识别/ASR、心电图上传与诊断、知识库问答、自评、三会 |
| case | 病例管理（Web） |
| audit | 病例三级审核（待审/工作台/历史） |
| template | 动态填报模板 |
| hospital | 医院/科室管理 |
| user | 医院用户管理 |
| stats | 数据统计与质控指标 |
| academy | 胸痛学院（课程/资料） |
| announcement | 公告管理 |
| value_added | 增值服务 |
| auth | 业务侧登录认证 |
| log | 业务日志 |

> 注：AI 能力全部集中在 `doctor` 与 `module_ai` 中，且仅 3 个真实功能（认证知识库问答、数据填报 AI 识别+语音识别、心电图 AI 诊断+协同总结）；`module_ai/chat`（通用 AI 对话）为孤儿功能，未接入任何页面。
