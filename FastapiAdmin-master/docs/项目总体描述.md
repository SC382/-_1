# 智慧胸痛中心管理平台 · 项目总体描述

> 版本 v3.1.0 ｜ 三端一体（Web 管理端 + App 医生端 + 数据大屏）｜ 面向胸痛中心/卒中中心等急危重症专科质控场景

---

## 一、项目概述

**智慧胸痛中心管理平台**（智慧胸痛管理）是面向区域胸痛中心建设的**专科专病信息化管理平台**，覆盖「患者建档 → 病例填报 → 审核质控 → 随访管理 → 数据分析」全流程，同时提供胸痛学院、三会模板、远程心电、智慧急诊等增值服务入口，并配套**运行数据大屏**（DataMAX）用于指挥中心展示。

系统由 **三端 + 一大屏** 构成：

```
┌────────────────────────────────────────────────────────────┐
│           智慧胸痛中心管理平台（v3.1.0）                      │
├───────────────┬───────────────┬───────────────┬─────────────┤
│  Web 管理端    │  App 医生端    │  DataMAX 大屏  │  AI 助手    │
│  (admin 运营)  │  (医生/审核)   │  (指挥中心)    │  (智能问答)  │
│  localhost:5180│  localhost:5190│  max.datahunter│  App 内嵌   │
└───────────────┴───────────────┴───────────────┴─────────────┘
                        │               │
                        ▼               ▼
              ┌──────────────────────────────┐
              │   FastAPI 后端 (0.0.0.0:8002) │
              │   /api/v1 动态路由自动发现     │
              └──────────────┬───────────────┘
                    ┌────────┴────────┐
                    ▼                 ▼
                 MySQL 8.x         Redis 7.x
              (业务数据/权限/日志)  (缓存/会话/参数/字典)
```

## 三、功能模块

### 1. 后端业务模块（动态路由自动注册，`/cpx` 容器 12 个子模块）

| 模块 | 说明 | 关键接口 |
|---|---|---|
| `auth` | 登录认证 / 角色权限 | `/cpx/auth/login`、BusinessRole 鉴权 |
| `user` | 用户 / 医生档案管理 | 账号 CRUD、`doctor_info` 档案 |
| `hospital` | 医院管理 | 医院 CRUD / 状态启停 |
| `case` | 病例管理 | 病例 CRUD、状态流转（draft→submitted→approved/rejected） |
| `template` | 填报模板 / 动态表单 | 模板 + 字段（6 大分类 60+ 字段：基本信息/院前急救/急诊分诊/检验检查/院内诊疗/介入手术/患者转归） |
| `audit` | 审核管理 | 审核记录、时间节点逻辑校验（FMC→心电图→PCI 时间链） |
| `stats` | 统计驾驶舱 | `/cpx/stats/dashboard`（驾驶舱聚合）、`/analysis`（统计分析/数据质量） |
| `doctor` | 医生端工作台 | 医生统计、病例创建 |
| `academy` | 胸痛学院 | 课程/学习内容 |
| `log` | 操作日志 | 系统操作审计 |
| `announcement` | **公告管理** | Web CRUD + 发布/下线 + App 端 active 列表/详情 |
| `value_added` | **增值服务管理** | Web CRUD + 上线/下线 + App 端 active 列表（h5/external/internal 三种跳转） |

### 2. Web 管理端（admin 运营）

- **首页驾驶舱**：4 张统计卡（医院/用户/病例/审核，数字滚动 + 骨架屏）+ 病例趋势图（日/月切换）+ 审核情况环图 + 医院病例排行 Top10 + 运行概览
- **公告管理**：公告 CRUD、发布/下线、富文本内容、排序
- **增值服务管理**：服务 CRUD、上线/下线、跳转类型配置
- 病例 / 模板 / 审核 / 医院 / 用户 / 学院 / 操作日志等常规管理页

### 3. App 医生端

- **首页工作台**：渐变头部 + 5 项病例统计（今日新增/草稿/待审核/已通过/驳回，点击跳转筛选）+ 白色公告轮播条 + 8 宫格功能入口 + 增值服务大卡（swiper 轮播）
- **数据直报**：患者建档 → 模板动态表单填报（发病/到院/心电图/PCI 等时间节点）
- **数据分析 / 随访管理 / 三会模板 / 胸痛学院 / 远程心电 / 智慧急诊** 等功能页
- **底部导航**：首页 / AI助手 / 我的（中间 AI Tab 差异化视觉）
- 公告详情页（富文本渲染）

### 4. 数据大屏（DataMAX）

- **智慧胸痛中心运行大屏**（1920×1080）：KPI 顶栏（累计病例/今日新增/待审核/通过率/覆盖医院/医护账号）+ 6 大图表（病例趋势、病种分布、医院排行、状态分布、救治时效、分医院明细），白底深字简洁医疗风
- Web 端首页可 iframe 嵌入（已验证无 X-Frame-Options 限制）

### 5. AI 助手

- App 端「AI 助手」Tab 提供智能对话问答

## 五、接口体系

- 统一前缀：`/api/v1`（`ROOT_PATH` 配置）
- 动态路由发现：`app.core.discover` 扫描 `plugin/*` 目录，自动注册各模块 `*Router`（无需手工维护路由表）
- 权限：`BusinessRole([ROLE_ADMIN / ROLE_DOCTOR / ROLE_AUDITOR])` 依赖注入，App 端只读接口按角色隔离（doctor 访问管理接口返回 403）
- 统一响应：`SuccessResponse{code, msg, data}` / 异常统一封装 `CustomException`（`app.core.exceptions`）

## 七、环境与启动

| 依赖 | 说明 |
|---|---|
| MySQL 8.x | 库名 `fastapiadmin`，账号 root/123456（见 `backend/env/.env.dev`） |
| Redis 7.x | localhost:6379，db 1 |
| Python 3.12 + uv | 后端依赖管理 |
| Node 18+ / pnpm | 前端依赖管理 |

```bash
# 1) 后端（自动建表 + 初始化 + 动态路由）
cd backend
uv run python -m uvicorn main:create_app --host 0.0.0.0 --port 8002 --factory

# 2) Web 管理端
cd frontend/web && pnpm dev        # http://localhost:5180

# 3) App 医生端
cd frontend/app && pnpm dev        # http://localhost:5190/app

# 4) 演示数据（可选，驾驶舱真实数据）
cd backend && ENVIRONMENT=dev uv run python -m app.scripts.seed_dashboard_data
```

## 八、项目特色

1. **三端一体**：Web 运营 + App 业务 + 大屏展示，一套后端 API
2. **动态路由插件化**：新增业务模块只需在 `plugin/` 下建目录，路由自动发现注册，无需改主程序
3. **模板驱动动态表单**：病例表单由 `report_template` 定义，字段/分类/必填可配置，支持多版本
4. **审核时间链质控**：自动校验「发病→到院→心电图→PCI」时间节点逻辑，输出数据质量报告
5. **真实数据驾驶舱**：KPI 数字滚动 + 骨架屏 + ECharts 三图，全部来自真实业务表聚合
6. **DataMAX 大屏联动**：大屏可 iframe 嵌入 Web 首页，白底医疗简洁风，支持快照回滚
7. **权限角色隔离**：管理员/审核员/医生三级角色，App 只读接口与 Web 管理接口严格隔离
8. **运行环境**：uv + pnpm 现代化工具链，Windows 一键部署脚本（deploy.bat / deploy.sh）
