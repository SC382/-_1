# 开发环境配置清单

> 本文档基于当前项目真实配置（`backend/app/config/setting.py`、`*.toml`、`requirements.txt`、`frontend/*/package.json`、`deploy.*`）整理。所有端口、版本、启动命令均为实测/约定值。

---

## 1. 基础环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| 操作系统 | Windows（推荐）/ Linux | 本项目以 Windows + phpstudy 集成环境实测 |
| Python | **>= 3.12** | `backend/pyproject.toml` 的 `requires-python`；后端使用虚拟环境 `.venv` |
| Node.js | **>= 20.19.0**（Web）/ >= 20.19.0 \|\| 22.12.0 \|\| 24.0.0（App） | `frontend/*/package.json` 的 `engines` |
| 包管理器 | pnpm（前端） / pip 或 poetry（后端） | 前端 `pnpm install`；后端依赖见 `requirements.txt` |
| MySQL | 8.0 | 异步驱动 `aiomysql` + 同步 `pymysql`；库名 `fastapiadmin`（phpstudy 默认 root/123456） |
| Redis | 7.x | 异步连接，默认 `localhost:6379`，db=1 |
| 代码生成器 | 可选 | 后端 `module_generator` 基于表结构生成前后端代码 |

> 数据库引擎同时支持 PostgreSQL（`asyncpg`/`psycopg`），但**当前部署与开发均使用 MySQL 8.0**（见 `setting.py` 默认 `DATABASE_TYPE`）。

## 2. 端口矩阵（必记）

| 端 | 端口 | 启动命令 | 访问地址 |
|---|---|---|---|
| 后端 API | **8002** | `uvicorn main:create_app --port 8002 --factory` | http://localhost:8002/api/v1/docs（Swagger） |
| Web 管理端 | **5180** | `pnpm dev`（vite --mode development） | http://localhost:5180/ |
| App 医生端（H5） | **5190** | `pnpm dev:h5`（uni） | http://localhost:5190/ |
| 文档站（可选） | 按 VitePress 配置 | `pnpm dev` | 本地文档 |

> 注：`setting.py` 中 `SERVER_PORT` 默认 8001，实际启动通过 `--port 8002` 覆盖。三端端口在 `deploy.sh`/`deploy.bat` 中固定。

## 3. 后端启动步骤

```bash
# 1. 进入后端目录并创建虚拟环境（仅需一次）
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows

# 2. 安装依赖
pip install -r requirements.txt
# 或：poetry install（若使用 pyproject.toml 元数据）

# 3. 配置环境变量
# backend/env/.env.dev 为实际配置；不得缺少，否则会去读不存在的 .env.None
# 关键项：DATABASE_*、REDIS_*、DEEPSEEK_*、ZHIPU_*、ENVIRONMENT=dev

# 4. 初始化数据库（首次）
python -m app.scripts.initialize
python -m app.scripts.init_cpx_data      # 胸痛业务种子数据

# 5. 启动（必须带 ENVIRONMENT=dev）
cd backend
ENVIRONMENT=dev ./.venv/Scripts/python.exe -m uvicorn main:create_app --host 0.0.0.0 --port 8002 --factory
```

⚠️ **最大启动坑**：不带 `ENVIRONMENT=dev` 时，`setting.py` 的 `env_file = ENV_DIR / f".env.{os.getenv('ENVIRONMENT')}"` 会去读 `.env.None`，导致数据库密码为空、报 `Access denied for user 'root'@'localhost'`。

> 后端**不带 `--reload`**：改了 `service.py`/`controller.py` 等后端代码后**必须手动重启**才生效。

## 4. 前端启动步骤

### Web 管理端（frontend/web）

```bash
cd frontend/web
pnpm install
pnpm dev            # → vite --mode development，端口 5180
```

### App 医生端（frontend/app，H5 模式）

```bash
cd frontend/app
pnpm install
pnpm dev:h5         # → uni，端口 5190（H5）
# 小程序模式：pnpm dev:mp-weixin
```

> ⚠️ App 端 dev server 可能只监听 IPv6 `[::1]:5190`，此时 `curl 127.0.0.1:5190` 返回 000 属正常，用 `curl "http://[::1]:5190/"` 验证。
> ⚠️ App 启动失败高发原因：`vite-plugin-uni-pages` 用 proper-lockfile 自建自删 `src/pages.json.lock`，删除操作会被安全拦截。解决：先用 Python `os.remove` 清掉 `frontend/app/src/pages.json.lock` 再启动。

## 6. 环境变量关键项（backend/env/.env.dev）

| 配置组 | 变量 | 用途 |
|---|---|---|
| 数据库 | `DATABASE_HOST/PORT/USER/PASSWORD/NAME` | MySQL 连接（默认 localhost:3306） |
| Redis | `REDIS_HOST/PORT/DB_NAME/PASSWORD` | 缓存与会话 |
| AI-DeepSeek | `DEEPSEEK_BASE_URL/API_KEY/MODEL` | 知识库问答、文字识别、心电图诊断 |
| AI-智谱 | `ZHIPU_BASE_URL/API_KEY/VISION_MODEL/ASR_MODEL` | 图片识别、语音识别、心电图视觉所见 |
| 环境 | `ENVIRONMENT=dev` | 决定加载哪个 `.env.{ENVIRONMENT}` |

> 已核实的"死配置"（代码中无任何引用，可忽略）：`OPENAI_VISION_*`、`OPENAI_KB_MODEL`、`OPENAI_BASE_URL/API_KEY/MODEL`（仅被孤儿功能 module_ai/chat 引用）。

## 7. 开发约定速查

- **页面标题权威源（App）**：`frontend/app/pages.config.ts`，运行时会覆盖 `pages.json`，不要直接改 `pages.json`。
- **动态路由**：新增业务模块只需在 `app/plugin/module_cpx/` 下建目录 + `controller.py`，无需手动注册。
- **字段字典**：`backend/app/plugin/module_cpx/fields.py` 是 67 标准字段唯一来源，前后端改动需同步。
- **代码生成**：`module_generator` 可根据表结构生成 controller/service/schema/vue 脚手架。
