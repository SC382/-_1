## 二、前置软件（版本要求）

| 软件 | 版本要求 | 用途 | 备注 |
|---|---|---|---|
| **Python** | **≥ 3.12**（实测 3.12/3.13 均可） | 后端运行时 | 与 uv 配合 |

| **Redis** | 7.x（实测 7.x 无密码） | 缓存/会话 | Windows 可用 Memurai 替代 |
| **Git** | 任意 | 版本管理 | - |

> ⚠️ 注意：后端 `requires-python = ">=3.12"`，不要用 Python 3.11 及以下。

## 三、数据库配置（MySQL）

```sql
-- 1) 创建数据库（字符集必须 utf8mb4，兼容 emoji/中文）
CREATE DATABASE IF NOT EXISTS fastapiadmin
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

-- 2) 账号（后端默认 root/123456，按需调整）
--    后端配置位于 backend/env/.env.dev
```

| 配置项 | 值 |
|---|---|
| DATABASE_TYPE | `mysql` |
| DATABASE_HOST / PORT | `localhost` / `3306` |
| DATABASE_USER / PASSWORD | `root` / `123456` |
| DATABASE_NAME | `fastapiadmin` |

> 表结构无需手工创建：后端首次启动 lifespan 自动 `create_all` 建表 + 初始化种子数据（幂等）。

## 六、后端环境准备（backend/）

### 6.1 安装依赖
```bash
cd backend
uv sync          # 按 pyproject.toml 锁定版本安装到 .venv
```

### 6.2 环境配置文件
```
backend/env/.env.dev        # 开发环境配置（MySQL/Redis/模型/端口）
```
关键项：`ENVIRONMENT = dev`、`SERVER_PORT = 8002`、`LOGGER_LEVEL = DEBUG`、`DEMO_ENABLE = False`。

### 6.3 启动后端
```bash
cd backend
uv run python -m uvicorn main:create_app --host 0.0.0.0 --port 8002 --factory
```
启动日志应出现：
```
✅ 动态路由发现完成: 共 2 个容器前缀（/cpx 12 子模块、/example）
✅ mysql数据库初始化完成      ← 自动建表 + 种子数据（幂等）
✅ Redis 连接初始化完成
✅ 1 个系统周期任务已注册（操作日志清理）
Swagger http://0.0.0.0:8002/api/v1/docs
```

### 6.4 演示数据（可选）
```bash
cd backend
ENVIRONMENT=dev uv run python -m app.scripts.seed_dashboard_data
```
生成近 12 个月病例 + 审核记录（已有 ≥60 条病例时自动跳过）。

## 八、App 医生端环境准备（frontend/app/）

```bash
cd frontend/app
pnpm install
pnpm dev        # H5：http://localhost:5190/app/
```

### 环境变量（关键：后端地址）
```
frontend/app/.env.development
VITE_API_BASE_URL = http://192.168.0.35:8002   # ← 改成你本机的后端 IP/端口！
```

> ⚠️ **必改项**：App 端默认写死了局域网 IP（192.168.0.35:8002），新环境需改为本机地址：
> - 真机/局域网调试：`http://<你的局域网IP>:8002`
> - 本机 H5 调试：`http://localhost:8002` 或 `http://127.0.0.1:8002`

验证：H5 打开 `http://localhost:5190/app/` → 医生端登录（`testdoctor / Doctor123`，或自行在后台创建医生账号）。

> 其他平台：`pnpm dev:mp-weixin`（微信小程序）、`pnpm dev:app`（App，需 HBuilderX 云打包）。

## 九、首次启动完整流程（按序执行）

```bash
# 1. 基础设施
启动 MySQL（phpstudy_pro 等）与 Redis（无密码 6379）

# 2. 后端
cd backend && uv sync
uv run python -m uvicorn main:create_app --host 0.0.0.0 --port 8002 --factory
#   ↑ 自动建表 + 初始化角色/医院/账号（admin/Admin123）

# 3.（可选）演示数据
cd backend && ENVIRONMENT=dev uv run python -m app.scripts.seed_dashboard_data

# 4. Web 管理端
cd frontend/web && pnpm install && pnpm dev

# 5. App 医生端（先改 .env.development 的后端 IP）
cd frontend/app && pnpm install && pnpm dev
```

## 十一、常见问题排查（本项目实测踩坑）

| 现象 | 原因 | 解决 |
|---|---|---|
| 后端启动报 `cannot import name 'CustomException' from 'app.common.response'` | 模块导入了错误位置 | `CustomException` 在 `app.core.exceptions`；`settings` 在 `app.config.setting` |
| App 首页接口 404 | 后端旧进程未重启，或 `VITE_API_BASE_URL` 指向错误地址 | 重启后端（新代码需重启才加载动态路由）；核对 .env.development |
| 浏览器 tab 标题还是 FastapiAdmin | 浏览器缓存 / vite-plugin-uni-pages 覆盖 pages.json | Ctrl+Shift+R 强刷；`index.html` `<title>` 优先改 |
| `pages.json.lock` 删除失败 | WorkBuddy 等工具链 safe-delete shim 拦截 | 用 HBuilderX 打开项目，或手动删除 lock 后重启 |
| 大屏白底不生效 | 模板内嵌 backgroundImage 盖住底色 | DataMAX 侧 `update-config --background-image ""` 清空 |
| AI 助手无响应 | OPENAI_API_KEY 无效/欠费 | 检查 .env.dev 的 DashScope Key |
| 驾驶舱数字全 0 | useCountUp 在 computed 内调用导致 watch 失效 | 已在顶层预创建 counter（当前版本已修复） |

## 十二、生产环境注意（dev → prod）

1. `ENVIRONMENT = prod`，`DEBUG = False`，设置 `PROD_CORS_ORIGINS`
2. 更换 `OPENAI_API_KEY` 与数据库/Redis 密码
3. 清理演示种子数据（`seed_dashboard_data` 数据与真实数据分库/分环境）
4. 前端构建产物部署：`web` → `pnpm build`；`app` → `pnpm build:h5` 等
5. 定时任务与日志清理策略确认（`system_cleanup_operation_log`）
