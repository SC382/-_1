# 智慧胸痛中心管理系统 · Web 端与 App 端流程图

> 两端操作流程与页面跳转关系。v3.1.0

---

## 一、Web 管理端流程图

```
登录（admin / auditor）
      │
      ▼ 按角色渲染菜单（MenuProcessor）
┌──────────────┬──────────────────────────┐
│ admin 主菜单  │   auditor 审核菜单        │
├──────────────┼──────────────────────────┤
│ 📊 驾驶舱     │   ✅ 审核工作台(统计)      │
│ 📋 病例管理   │      ↓ 前往待审           │
│ 🧩 模板管理   │   📥 待审核列表           │
│ 🏥 医院管理   │      ↓ 点击详情           │
│ 👤 用户管理   │   🔍 审核详情(时间链校验)  │
│ 📢 公告管理   │      ↓ 处理              │
│ 🎁 增值服务   │   ✅ 通过→自动生成随访     │
│ 🎓 学院管理   │   ❌ 驳回(必填原因)       │
│ 🧾 系统日志   │   🗂 审核记录             │
│ ⚙️ 框架后台   │                          │
└──────────────┴──────────────────────────┘
```

### 页面操作流程
- **模板管理**：列表 → 新建模板 → 复制标准字段/添加字段 → 分类管理 → 发布（App 端即生效）
- **病例管理**：列表(卡片/表格) → 详情（基础+动态表单+审核记录）→ 删除（级联）
- **公告/增值/学院**：新建 → 发布/上线 → App 端首页/入口展示；下线 → 停止展示
- **用户/医院**：新增 → 编辑 → 批量启停；医生自动建档案、审核员建档案
- **系统日志**：列表 → 按角色筛选 → 查看留痕

### 审核员流程（Web 独有）
```
审核工作台 → 待审列表 → 审核详情（数据完整性+时间链校验提示）
→ 通过（写 audit_record pass + 自动生成 1/3/6/12 月随访）
→ 驳回（必填原因，医生 App 端看反馈整改后重新提交）
```

## 二、App 医生端流程图

```
登录（doctor）→ 首页工作台
  ├─ 📊 统计卡点击 → 数据直报页（?status / ?range=today 自动筛选）
  ├─ 📢 公告轮播 → 公告详情
  ├─ 🎁 增值服务卡 → 内页/H5/外链
  └─ 8 宫格：
      ├ 📝 数据直报 → 列表 → 新建建档 → AI识别预填 → 模板填报 → 保存/提交
      ├ 📄 病例详情 → 表单/时间轴/质控分析
      ├ 📈 今日报告 → 统计卡(5) → 跳数据直报筛选
      ├ 📊 数据分析 → 个人概览（累计/诊断分布/趋势）
      ├ 🩺 随访管理 → 待随访/已完成/已过期 → 提交随访
      ├ 💓 远程心电 → 上传 → AI诊断 → 协同会诊 → 反馈
      ├ 🗂 三会模板 → 选类型/病例 → 生成PPT
      ├ 🎓 胸痛学院 → 列表/详情（浏览量+1）
      └ 🏥 救治医院 → 医院列表
底部 Tab：🏠 首页 ｜ 🤖 AI助手（问答/识别/自评）｜ 👤 我的（资料/改密/设置）
```

### 核心填报流程（App）
```
患者建档(case-create) → 模板表单填报(case-fill，6 分类动态表单)
→ 保存草稿(draft) / 提交审核(submitted)
→ 驳回后查看反馈 → 修改 → 重新提交
→ 通过后系统自动生成随访计划 → 随访管理执行
```

## 三、两端流程衔接

```
Web 建模板/发公告/配增值 ──→ App 填报/首页展示
App 建档填报提交 ──→ Web 审核员审核 ──通过──→ 自动生成随访 → App 随访执行
App 填报数据 ──→ Web 驾驶舱/大屏汇总
```

## 四、关键入口对照

| 入口 | Web 端 | App 端 |
|---|---|---|
| 登录 | admin/auditor 账号 | doctor 账号（或审核员） |
| 病例 | 全量管理（admin） | 本人填报/查看 |
| 审核 | ✅ Web 操作（工作台/通过/驳回） | 无审核页 |
| 随访 | 无页面（数据进驾驶舱） | ✅ 执行随访 |
| 模板 | ✅ 配置/发布 | 只读使用 |
| 内容发布 | ✅ 公告/增值/学院 | 消费展示 |
