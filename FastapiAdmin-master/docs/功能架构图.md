# 智慧胸痛中心管理系统 · 功能架构图

> 功能维度架构（区别于目录框架），基于真实页面/接口梳理。v3.1.0

---

## 一、Web 管理端功能（admin / auditor）

| 功能模块 | 核心功能 | 说明 |
|---|---|---|
| **运营驾驶舱** | KPI 统计 · 病例趋势(日/月) · 审核环图 · 医院排行 · 运行概览 | 全中心数据实时聚合（5 表） |
| **病例管理** | 全量列表（卡片/表格双视图）· 详情 · 级联删除 | admin 视角，跨医院 |
| **模板管理** | 模板 CRUD · 字段配置 · 分类管理 · 发布/取消发布 · 复制标准字段 | 动态表单"图纸"，Web 独有 |
| **审核管理** *(auditor)* | 审核工作台 · 待审列表 · 详情(时间链校验) · 通过/驳回 · 记录 | 审核员在 Web 操作，通过自动生成随访 |
| **医院管理** | 医院 CRUD · 批量启停 | 下拉选项供业务引用 |
| **用户管理** | 医生/审核员账号 · 档案联动 · 重置密码 · 批量启停 | 三档角色分配 |
| **公告管理** | 发布/下线/排序 → App 首页轮播 | Web 发布 App 消费 |
| **增值服务管理** | 服务卡片配置/上下线 → App 首页大卡 | 支持内页/H5/外链 |
| **胸痛学院** | 资源上传(PPT/视频/PDF) · 分类 · 发布 → App 学习 | 浏览量统计 |
| **系统日志** | 操作留痕查询 · 角色筛选 | 写操作自动落库 |
| **框架后台** | 菜单/角色/部门/字典/参数/岗位/通知/工单/版本/聊天 等 13 模块 | FastapiAdmin 通用能力 |

## 二、App 医生端功能（doctor）

| 功能模块 | 核心功能 | 说明 |
|---|---|---|
| **首页工作台** | 5 项统计 · 公告轮播 · 增值服务大卡 · 8 宫格入口 | onShow 并发拉取 3 接口 |
| **数据直报** | 状态 Tab/日期筛选 · 建档 → 模板填报 → 保存/提交 | 核心业务，含 AI 识别预填 |
| **病例表单** | 模板驱动动态表单（6 大分类）· 时间轴 · 质控分析 | form_data JSON 存储 |
| **随访管理** | 1/3/6/12 月计划（按患者聚合）· 提交随访 | 审核通过自动生成 |
| **今日报告** | 今日统计卡(5) · 今日明细 · 点击跳转筛选 | 新功能 |
| **远程心电** | 心电上传 · AI 诊断 · 协同会诊(状态机) | draft→…→closed |
| **三会模板** | 质量会/联合例会/典型病例讨论 PPT 生成 | 记录 meeting_record |
| **胸痛学院** | 已发布资源列表/详情（浏览量+1） | Web 发布 App 学习 |
| **数据分析** | 个人数据概览（累计/诊断分布/趋势） | doctor/stats/overview |
| **救治医院** | 救治单元/医院列表 | 下拉引用 |
| **AI 助手 · 鲲仑平安** | 知识库问答(流式+来源标注) · 图片/文字识别(动态字段) · 认证自评 | DeepSeek 驱动 |
| **我的** | 个人信息 · 修改密码 · 设置(中英) · 退出 | - |

## 三、共享底座（两端共用）

| 能力 | 内容 |
|---|---|
| **认证权限** | JWT 登录 · Redis 会话 · BusinessRole 三档角色(admin/auditor/doctor) 接口级隔离 |
| **数据服务** | MySQL 20 表 · Redis(会话/参数/字典/任务) · 模板驱动动态表单(form_data JSON) |
| **AI 服务** | DeepSeek v4-flash(问答/文字) · v4-flash-vision-exp(图片, base64 内联) |
| **系统能力** | 定时任务(日志清理) · 操作日志 · 文件上传(static/uploads) |

## 四、跨端功能协同

```
Web 建模板 ──→ App 按模板填报 ──→ App 提交 ──→ Web 审核(时间链校验) ──→ 通过→自动生成随访 → App 执行随访
                                                              └─→ 驳回 → App 整改再提交
Web 发公告/增值服务/学院 ──→ App 首页/入口实时展示
App 填报/随访数据 ──→ Web 驾驶舱/统计分析/大屏
```
